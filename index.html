Hasil Hash

HMAC — Hash-based Message Authentication Code

HMAC membuktikan dua properti sekaligus: integritas (file tidak berubah) + autentisitas (berasal dari pihak yang punya secret key). Hash biasa hanya membuktikan integritas.

🔑
Cara Kerja: HMAC = H(key ⊕ opad ∥ H(key ⊕ ipad ∥ message))
Tanpa mengetahui secret key, penyerang tidak bisa memalsukan HMAC meski tahu isi file.

Avalanche Effect Visualizer

Demonstrasi sifat kriptografi: perubahan 1 karakter input mengubah ~50% bit output hash.

🏔
Mengapa penting? Ini membuktikan hash bersifat unpredictable — kecil pun perubahan input tidak bisa diprediksi outputnya, sehingga tidak bisa di-reverse atau dimanipulasi secara parsial.
